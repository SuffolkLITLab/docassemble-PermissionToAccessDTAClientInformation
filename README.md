# DTA information release

Help a Massachusetts DTA client give one trusted person or group permission to discuss their SNAP, TAFDC, or EAEDC case. The interview makes a Voluntary Consent to Release Information (VARI-OI) for the client to print, sign, and send. It uses an Agency ID or the last four digits of the client's SSN; it never asks for a full SSN.

This consent does not let someone sign applications or use the client's benefits. Permission lasts one year unless the client cancels it. Helpers may enter answers, but the client signs the form.

Entry point: `docassemble.PermissionToAccessDTAClientInformation:data/questions/permission_to_access_dta_client_information.yml`.

The Word template preserves the consent language of the [official DTA VARI-OI form](https://www.mass.gov/lists/voluntary-consent-to-release-information), with space for long names and addresses. [MassLegalHelp's sample consent](https://masslegalhelp.org/sites/default/files/2024-02/Appendix%20C_2024%20SNAP%20Guide.pdf) also covers SNAP or cash benefits. [MassLegalServices explains permission to talk with DTA](https://www.masslegalservices.org/content/08-can-i-give-someone-permission-talk-dta-about-my-snap-case).
